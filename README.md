# Levi Deurloo — Portfolio (v2)

## Quick start

```bash
npm install
npm run dev
```

Visible at `http://localhost:5173`.

## Directory structure

```
src/
├── assets/scss/       Design tokens, thema (dark/light), aurora-animatie
├── components/        Herbruikbare UI (NavRail, ProjectCard, ThemeToggle, …)
├── sections/          Pqge-sections (Home, About, Portfolio etc)
├── composables/      
├── services/         
├── data/                
└── types/            
```

## Build (production)

```bash
npm run build
npm run preview   # lokaal de productiebuild bekijken
```

Output in `dist/`.
